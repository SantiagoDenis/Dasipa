# SCRUM-36 — accesibilidad y rendimiento

Estilos responsive, foco visible, áreas táctiles, respeto de movimiento reducido, navegación semántica y estados de error. Imágenes SVG locales de productos, sin librería de animaciones ni fuentes remotas. Verificaciones de compilación y revisión manual se registran en la entrega integrada. No se agregan tests automatizados por pedido del usuario. Auditoría WCAG y objetivos de rendimiento medidos en hosting real pendientes; no atribuir un puntaje Lighthouse no ejecutado.

# SCRUM-21 — Catálogo administrable

CRUD sin borrado destructivo, borrador/publicado, variantes/precios/stock y registro de autor. APIs requieren admin aprobado. Medios limitados a SVG propios y PDF HTTPS del dominio oficial; carga de archivos binarios a storage queda pendiente, no se acepta URL arbitraria. Las fichas y pedidos guardan sus referencias históricas. Requiere matriz validada para datos reales.

# SCRUM-25 — Alta y acceso

Registro B2B pendiente, verificación de correo con token hash y vencimiento, recuperación con un solo uso y revocación de sesiones. PBKDF2 y cookie HttpOnly. En demo se muestra el enlace de verificación/recuperación; fuera de demo solo se genera outbox. Correo real y revisión documental de CUIT siguen pendientes. No usar datos personales reales.
